# Wine Cellar · ระบบสต็อกไวน์

Vite + React 19 + TypeScript + Supabase ตามโครงใน `Vite Supabase Project Structure.md`

## เริ่มใช้งาน

```
npm install
cp .env.example .env.local   # VITE_ENABLE_MOCK=true
npm run dev
```

โหมด mock ไม่ต้องมี Supabase project: login ด้วยอีเมลใดก็ได้ รหัสผ่าน `password`
ข้อมูลทดลองเก็บใน localStorage กด "รีเซ็ตข้อมูลทดลอง" ที่แถบซ้ายเพื่อเริ่มใหม่

### ตารางแบบ Excel (`src/components/data-grid`)

- คลิก/ลากเลือกช่วง · Shift+คลิก · คลิกเลขแถว/หัวคอลัมน์เลือกทั้งแถว/คอลัมน์
- ดับเบิลคลิก, Enter, F2 หรือพิมพ์ทับเพื่อแก้ · แตะซ้ำบนจอสัมผัส
- ปุ่มกรองที่หัวคอลัมน์: เรียง, ค้นหา, ติ๊กเลือกค่า · เรียงได้หลายคอลัมน์ (คอลัมน์ที่เลือกทีหลังเป็นลำดับรอง มีเลขลำดับที่หัวคอลัมน์) · ปุ่ม ▾ ในเซลล์เปิดรายการตัวเลือกที่ใช้บ่อย · ทุกการค้นหา/กรอง/เรียงที่ใช้อยู่แสดงเป็นชิปเหนือตาราง กด × ยกเลิกทีละอัน หรือ "ล้างทั้งหมด" (หน้าความเคลื่อนไหวและป้าย QR ก็มีชิปตัวกรองของหน้า) · ตรึงคอลัมน์ไว้ทางซ้ายได้ (กดไอคอนหมุดที่หัวคอลัมน์ หรือเมนูหัวคอลัมน์ · จำแยกตามตาราง) ค่าตั้งต้นตรึงเฉพาะ Name of wine · ตรึงเพิ่มแล้วเรียงซ้าย→ขวาตามลำดับที่กด · Maturity: พิมพ์ปีในช่องค้นหาของตัวกรอง เช่น 2030 = ไวน์ที่ช่วงดื่มได้ครอบคลุมปีนั้น
- คลิกขวา: แทรก/ลบแถว, ล้างค่า · ลากขอบหัวคอลัมน์เพื่อปรับความกว้าง
- ปิดคัดลอก/วางกับ Excel (Ctrl+C/V/X) · ย้อนกลับ (Ctrl+Z/Y) · ลากมุมคัดลอก ทุกตาราง (เปิดได้ด้วย `clipboard` ของ DataGrid) · ข้อมูลจากไฟล์ใช้ปุ่มนำเข้าแทน
- แถบล่างแสดงผลรวมของเซลล์ตัวเลขที่เลือก
- สีสถานะ: แถวเพิ่มใหม่ = เขียว · เซลล์ที่แก้ = เหลือง (เฉพาะคอลัมน์ที่เปลี่ยน) · แถวที่ลบ = แดงขีดฆ่า · แถบล่างบอกจำนวนแต่ละแบบ
- คอลัมน์ Store เป็นตัวเลือกแบบพิมพ์ค้นหาได้ (หลายคำ เช่น "room 2") · คอลัมน์วันที่เปิดปฏิทินให้เลือกเมื่อแก้

- แบ่งหน้า เลือก 25 / 50 / 100 / 200 / ทั้งหมด ต่อหน้า (จำค่าที่เลือกไว้ต่อหน้าจอ) · วางจาก Excel ล้นไปหน้าถัดไปได้ · หน้าประวัติแบ่งหน้าฝั่ง server เลือก 10 / 20 / 50 / 100

## ต่อ Supabase จริง

1. รัน migration ใน `supabase/migrations/` ตามลำดับ (ตาราง + RLS + function รับเข้า/เบิก/ยกเลิก + `stock_item_logs` กับ trigger เก็บประวัติ + `save_stock_changes`)
2. สร้างผู้ใช้ใน Supabase Auth
3. ตั้ง `.env.local`: `VITE_ENABLE_MOCK=false`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` (publishable/anon key เท่านั้น)
4. `npm run db:types` เพื่อ generate `src/lib/database.types.ts` ทับไฟล์ที่เขียนมือไว้

## เพิ่มการตั้งค่าใหม่

- **ค่าระบบใหม่** (เปิด/ปิดฟีเจอร์ ตัวเลข เกณฑ์ต่างๆ): เพิ่ม key ใน `src/features/settings/app-settings.ts` (zod schema + default) แล้วเพิ่มช่องในหน้า "ทั่วไป" — ไม่ต้องแก้ DB เพราะ `app_settings` เป็น key/value
- **หัวข้อเมนูใหม่**: เพิ่มรายการใน `src/features/settings/registry.ts` และสร้าง route `src/routes/_authenticated/settings/<ชื่อ>.tsx` (รายการที่ไม่มี `to` จะแสดงเป็น "เร็วๆ นี้")
- **ตัวเลือกประเภทใหม่** (เช่น พันธุ์องุ่น): เพิ่มค่าใน check constraint ของ `lookup_values.category` และใน `CATEGORIES` ของหน้าตัวเลือก

## กติกาข้อมูล

- ไม่มีการลบแถวจริง: `stock_items.deleted_at`, เอกสารใช้ `status = 'void'` (ไม่มี RLS policy สำหรับ delete)
- `balance` แก้ได้ผ่าน function เท่านั้น (ไม่ได้ grant update คอลัมน์นี้)
- รับเข้าจับคู่ไวน์เดิมด้วย คลัง + ชื่อ + ปี + rack (unique index `stock_items_identity_uq`)
- บรรทัดเอกสารเก็บ snapshot ข้อมูลไวน์ ณ วันที่ทำรายการ
- คะแนน (Rate) เก็บเป็นข้อความ `rating` ใส่ได้หลายค่า เช่น `100RP, 98WS, 95JS` — ตัวเลขตามด้วยตัวย่อนักวิจารณ์ (พิมพ์ `100 rp 98ws` ระบบจัดรูปแบบให้ · นักวิจารณ์ซ้ำใช้ค่าแรก) แสดงเป็นชิปต่อค่า
- ทุกการเปลี่ยนแปลงของ `stock_items` ถูก trigger เขียนลง `stock_item_logs` (ใครก็แก้โดยไม่ทิ้งร่องรอยไม่ได้)
